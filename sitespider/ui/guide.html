快速開始

1
啟動控制台 在專案目錄執行 bash scripts/dev-ui.sh，瀏覽器開啟 爬取中心。
2
填寫網址並爬取 輸入客戶網站首頁 URL、客戶名稱，按「開始爬取」。可先點「試跑 12 頁」限制規模。
3
開啟交付 完成後進入步驟 3，點「開啟交付導覽」或下載 ZIP，交給客戶離線閱讀。

不確定效果時，可先開 範例報告 熟悉報告結構。

爬取中心三步驟

頂部情境列顯示目前步驟；右側欄會依步驟切換內容（快速開始／即時監控／交付小幫手）。

① 設定

  • 填寫客戶網站網址（建議含 https:// 與尾端斜線）。
  • 客戶／專案名稱會出現在任務列表與交付摘要，方便日後找回。
  • ＋ 新爬取：清除目前任務畫面，回到步驟 1 重新設定（不刪除舊報告檔案）。
  • 目前任務下拉：快速切換最近完成的爬取。

② 爬取

  • 中央顯示進度環與目前 URL；右側「即時監控」顯示已爬頁數、問題命中與 Top 問題。
  • 匯出分階段：爬取 → 快速匯出 → 完整匯出；快速完成後可先進入交付預覽。

③ 交付

  • 左欄：健康分、主要 CTA、ZIP／分享、主要問題。
  • 右欄：全部交付檔案（可搜尋檔名）。
  • 右側「最近任務」可一鍵回到某次報告；底部可「清除所有最近任務」（僅隱藏列表，不刪 reports/）。

AI 文案功能

AI 使用您選擇的 LLM 平台 API 金鑰（OpenAI、Google Gemini、Anthropic 等），與 Search Console 憑證無關。

設定方式

  1. 前往 AI 文案 頁（或爬取中心右側連結）。
  2. 選擇 AI 平台 與 模型（可篩選模型名稱）。
  3. 填入該平台的 API 金鑰；可勾選「爬取完成後自動產生 AI 文案」。
  4. 按「儲存 AI 設定」。金鑰預設存於瀏覽器本機；伺服器亦可透過環境變數集中設定。

產生時機

  • 爬取完成後，在步驟 3 按 ✨ AI 文案。
  • 或勾選自動產生，背景執行完成後可開 ai-hub.html。
  • 「最近任務」中若已有 AI，會顯示 AI 交付 按鈕。

Google Search Console（GSC）

GSC 用於查詢 Google 已索引狀態與 Rich Results，需要Google Cloud 憑證，不是 Gemini API Key。

適用方案

Pro、Agency 方案含 GSC Rich Results 檢查（見方案功能）。

前置安裝

pip install "sitespider[gsc]"
# OAuth 方式還需 google-auth-oauthlib（通常已包含在 [gsc] 額外依賴）

憑證（二擇一）

  1. 服務帳戶 JSON：在 Google Cloud 建立服務帳戶，下載 JSON，並在 Search Console 將該服務帳戶加為網站使用者。設定環境變數： GOOGLE_APPLICATION_CREDENTIALS=/path/to/service-account.json 或 GSC_CREDENTIALS_JSON 指向同檔案。
  2. OAuth 用戶端：使用 Google Cloud「桌面應用程式」OAuth 用戶端 JSON。設定 GSC_OAUTH_CLIENT_JSON=/path/to/client_secret.json，首次執行爬取並啟用 GSC 時會開瀏覽器登入，token 存於 ~/.config/sitespider/gsc-oauth-token.json。

在爬取中心啟用

  1. 展開進階選項。
  2. Search Console 檢查：填大於 0 的數字（例如 10），表示最多檢查幾個 URL。
  3. Search Console 資源網址：填 GSC 資源格式，通常與站點一致，例如 https://www.example.com/（網域資源或 URL 前綴須與 Console 內一致）。
  4. 設為 0 則完全不呼叫 GSC，其餘報告仍可正常產出。

產出

  • rich_results_gsc.csv — 各 URL 的索引／複合式結果狀態。
  • 報告內文可能註明本次 GSC 檢查筆數。

路徑：帳號與方案。

  • 租戶 ID（tenant_id）：多客戶／多專案時區分報告目錄，預設 default。

排程爬取

在爬取中心右側（步驟 1 或 3 的交付小幫手區）展開 排程爬取，按「產生 cron 指令」Pro+。

會依目前 tenant、方案與設定檔路徑產生每週執行的 shell／cron 範例，可貼到伺服器 crontab 定期重跑並用「比對」追蹤回歸。

報告比對

在「最近任務」卡片上，若方案含 compare，且存在更早一筆完成任務，會顯示 比對 按鈕。

比對兩次 crawl-report.json，產生 compare-report.html，標示問題新增／解決與回歸項目。

客戶分享連結

步驟 3 按 🔗 分享連結，系統建立有時效的只讀 Portal（預設約 30 天）。

常見問題

為什麼報告開起來樣式跑版或沒有頂欄？

請用 http://127.0.0.1:8765/reports/… 開啟，不要用檔案總管雙擊 HTML。舊匯出報告可重新爬取匯出以取得最新頂欄。

首頁被導到舊任務步驟 3？

網址勿帶舊的 ?job=；點頂欄「＋ 新爬取」或開 /?step=1。

Lighthouse／JS 渲染無法勾選？

代表本機尚未安裝對應工具；步驟 1 上方黃色說明框有安裝指引，不影響一般爬取。

AI 頁面顯示模型已下線？

到 AI 文案 改選建議模型或自訂模型名稱後重新儲存並產生。
