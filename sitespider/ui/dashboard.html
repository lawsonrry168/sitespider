Lighthouse 速度檢測尚未就緒

此功能會對部分頁面跑 Google Lighthouse，在報告中附上載入速度、LCP、行動版體驗等分數。沒有安裝也不影響一般爬取與 SEO 問題檢查。

若要啟用，請在本機（執行 SiteSpider 的那台電腦）安裝：

  1. 安裝 Node.js（建議 LTS 版）
  2. 在終端機執行：npm install -g lighthouse
  3. 重新啟動 bash scripts/dev-ui.sh，再到「進階選項」勾選 Lighthouse

JavaScript 渲染尚未就緒

適用於React、Vue、Nuxt等由瀏覽器動態產生內容的網站。開啟後會用真實瀏覽器載入頁面，才能抓到 JS 執行後的標題、連結與文字（一般 HTTP 爬蟲可能只看到空白殼）。

沒有安裝時仍可爬一般靜態／伺服器輸出 HTML 的網站；「JS 渲染」選項會維持停用。

若要啟用，在專案目錄執行：

  1. pip install 'sitespider[browser]'（或 pip install -e '.[browser]'）
  2. playwright install chromium
  3. 重新啟動控制台後，在進階選項勾選「JavaScript 渲染」

首次安裝會下載 Chromium，約需數百 MB 與數分鐘時間。
