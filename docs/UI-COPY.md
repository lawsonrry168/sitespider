# SiteSpider 對外文案對照

維護頂欄名稱：`sitespider/ui/topnav.js`

| 內部／舊稱 | 對外名稱 |
|-----------|----------|
| 控制台 / console | **爬取中心** |
| 工作區 · API / 租戶 | **帳號與方案** / 帳號 ID |
| 顧問白標 / 白標 | **報告品牌** |
| AI 潤飾 | **AI 文案** |
| 訂閱 | **方案價格** |
| 示範 / 煙霧爬取 | **範例報告** / 試跑 |
| 管理後台 | **營運**（頂欄）／營運後台（頁內） |
| SF 報告 | **站內技術報告** |
| AI 交付 / FAQ CMS | **AI 交付**、**FAQ 貼上**（需先產生 AI 文案；FAQ 貼上＝ CMS 用 FAQ 區塊） |
| GSC | **Search Console**（首次出現可寫全名） |
| Fast / Standard 匯出 | **快速匯出** / **完整匯出** |
| Portal | **客戶分享連結** |
| API Key | **API 金鑰** |
| Stripe Portal | **訂閱管理頁** |
| 仅存本机 | **僅保存在本機瀏覽器** |
| 關於我們 / 聯絡我們 | 頁尾 + 頂欄「更多」選單；主選單：爬取中心、範例、方案、AI |
| 品牌副標（頂欄） | 統一 **SEO · GEO 顧問交付**（頁面標題用 `h1.page-title`） |

技術欄位 ID（`tenant_id` 等）不變，僅改畫面標籤與說明文字。

聯絡信箱可由環境變數 `SITESPIDER_CONTACT_EMAIL` 覆寫；營運主體名稱：`SITESPIDER_COMPANY_NAME`。
