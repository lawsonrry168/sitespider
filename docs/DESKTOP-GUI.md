# SiteSpider 桌面版 GUI 設計（UX 規格）

**設計定位**：24–27 吋顧問工作站的「駕駛艙」— 長時間爬取、對照報告、切換任務時眼睛與滑鼠都省力。  
**設計語言**：延續 Washi Indigo（藍染底、若竹 accent、和紙淺色），密度中等（非擠爆表格、非大片留白）。

---

## 一、為何桌面要獨立版面？

| 現狀（窄版／行動優先） | 桌面痛點 | 桌面 GUI 解法 |
|------------------------|----------|----------------|
| 頂欄塞滿 5+ 連結 | 視線左右跳、易誤點 | **左側固定導覽** |
| 三步橫向捲動 | 大螢幕浪費、步驟感弱 | **左欄垂直流程** |
| 右欄 300px 易掉下方 | 需上下捲動找任務 | **右欄固定高度內捲動** |
| 主區 max-width 1280 置中 | 兩側黑邊、交付表格窄 | **主區撐滿、右欄 360px** |
| 無全域狀態 | 不知目前步驟與快捷鍵 | **底部狀態列** |

窄於 **1100px** 時自動回到原本 `console-layout`（單欄 + 橫向三步），同一套 HTML。

### 區域職責

| 區域 | 內容 | 原則 |
|------|------|------|
| **左欄** | 全站導覽、垂直三步、使用說明 | 永遠可見，減少頂欄擁擠 |
| **工具列** | 當步標題、副標、任務下拉、新爬取、說明連結 | 只描述「現在在做什麼」 |
| **中央** | 主要操作與結果 | 捲動發生在中央，不帶走左右欄 |
| **右欄** | 輔助與歷史 | 顧問高頻：最近任務、即時數字 |
| **狀態列** | 步驟 x/3、快捷鍵 | 減少抬頭找提示 |

## 三、舒適度原則（大螢幕）

1. **字級**：沿用 `comfort-display.css`，1080p 以上正文 ≥ 16px，標題層級分明。  
2. **行距**：正文 `line-height: 1.7`，表單 label 與輸入間距 ≥ 0.5rem。  
3. **對比**：正文 `#ebe9e3` on `#0c0e14`（深色）；淺色和紙模式同步 tokens。  
4. **點擊目標**：側欄選項、三步按鈕高度 ≥ 40px，適合滑鼠。  
5. **捲動分區**：僅中央與右欄內捲動，避免整頁抖動。  
6. **減少橫向捲動**：交付步驟以 CSS Grid 雙欄呈現（`delivery-split`）。  
7. **鍵盤**：`1` `2` `3` 切步、`⌘/Ctrl+Enter` 開始、`Esc` 回設定（狀態列常駐提示）。

## 四、各步驟桌面行為

### 步驟 1 — 設定

- 主欄：表單最大寬度放寬；≥1280px 時「客戶名稱／模式」**雙欄並排**。  
- 右欄：快速開始 + 最近任務（與現有 rail 相同）。  
- 首次提示橫幅可關閉，關閉後記憶。

### 步驟 2 — 爬取

- 主欄：進度與日誌區最大寬 ~56rem，避免過長行難讀。  
- 右欄：即時監控（頁數、問題數）始終可見。

### 步驟 3 — 交付

- 主欄：`delivery-layout` 左「結果摘要／問題」、右「檔案清單」雙欄。  
- 右欄：交付捷徑、排程（方案允許時）。

## 五、啟用方式

| 方式 | 說明 |
|------|------|
| 視窗寬度 ≥ 1100px | 自動 `html.ss-desktop` |
| `?desktop=1` | 強制桌面版（本機 .exe 啟動預設帶此參數） |
| `?desktop=0` | 強制窄版配置 |
| `localStorage sitespider-desktop-layout=1` | 記住偏好 |

**程式檔**

- `sitespider/ui/desktop-gui.css` — 版面  
- `sitespider/ui/desktop-shell.js` — 導覽注入、流程搬移、狀態列  
- 僅 `dashboard.html` 載入（爬取中心）

---

## 六、與 .app / .exe 的關係

`desktop_launcher` 啟動伺服器後：

1. 預設以 **pywebview 內嵌視窗** 開啟 `/?desktop=1`（無 pywebview 則改系統瀏覽器）。
2. 所有控制台頁面自動帶 `desktop=1` 參數（內部連結亦會補上）。

---

## 七、其他控制台頁（說明、方案、AI…）

凡 `body.app-console` 且非爬取中心者，寬螢幕下由 `desktop-chrome.js` **自動包裝**：

- 左欄：與爬取中心相同的主選單（無垂直三步）。
- 中央：全寬可捲動內容區。
- `desktop-pages.css`：說明雙欄目錄、方案雙欄卡片等。

涵蓋：`guide`、`pricing`、`ai`、`workspace`、`branding`、`about`、`contact`、`admin`、`sites`、`demo` 等。

---

## 八、右欄寬度拖曳（爬取中心）

- 主欄與右欄之間有 **6px 拖曳把手**（`#ss-rail-resizer`）。
- 寬度 **280–520px**，預設 360px，存入 `localStorage`（`sitespider-rail-width`）。
- 鍵盤聚焦把手後 `←` `→` 以 16px 調整。
- API：`SiteSpiderDesktop.setRailWidth(400)`（除錯用）。
